ScrollSpeed PROBE v4 - read-only diagnostic (changes nothing, no mouse hook)

1. Delete the old ScrollSpeed.asi / ScrollSpeed.ini / ScrollSpeed.log from bin64, then copy these two files in.
   Make sure only ONE ASI loader is present (winmm.dll OR version.dll, not both).
2. Start the game, load a save, wait ~60 s. (F6 scans again.) The scan can take a while; the game may hitch.
3. Send me bin64\ScrollSpeedProbe.log.
